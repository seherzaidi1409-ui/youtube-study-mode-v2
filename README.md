# YouTube Study Mode (YSM) — Version 2

A Chrome extension designed to make YouTube a more focused learning environment by reducing distracting content while keeping educational videos accessible.

## About the Project

YouTube is widely used by students for educational content, tutorials, and lectures. However, features such as YouTube Shorts, video recommendations, and suggested content can interrupt study sessions.

YouTube Study Mode aims to address this problem without blocking YouTube entirely.

## Features

- **Hide YouTube Shorts:** Reduces exposure to Shorts.
- **Hide Home Recommendations:** Removes recommended videos from the YouTube homepage.
- **Hide Related Videos:** Removes the suggested-video sidebar while watching a video.
- **Hide End-Screen Suggestions:** Reduces recommended videos displayed at the end of playback.
- **Study Mode Toggle:** Allows users to turn distraction filtering on or off.
- **Persistent Settings:** Remembers the Study Mode setting across page refreshes.

## Installation

1. Download or clone this repository.
2. Open Google Chrome and navigate to `chrome://extensions`.
3. Enable **Developer mode**.
4. Select **Load unpacked**.
5. Choose the project folder.
6. Open YouTube and activate Study Mode through the extension.

## How It Works

When Study Mode is enabled, the extension applies CSS-based filters to selected YouTube interface elements.

The goal is to reduce distractions without removing access to YouTube search or educational videos.
