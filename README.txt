YOUTUBE STUDY MODE — VERSION 2

WHAT'S NEW
- A redesigned popup with clearer Study Mode status.
- Customizable filters for Shorts, YouTube Home feed, related-video sidebar, and end-screen suggestions.
- Settings save automatically and persist using chrome.storage.local.
- Content filters reapply after YouTube's single-page navigation.

INSTALL IN CHROME
1. Extract this ZIP file.
2. Open chrome://extensions in Chrome.
3. Turn on Developer mode.
4. Click "Load unpacked".
5. Select the extracted folder named "youtube-study-mode".
6. Open YouTube and click the extension icon.

IMPORTANT
- This is a prototype and uses YouTube page selectors that may change as YouTube updates its interface.
- It cannot guarantee removal of every distracting video.
- "Hide home feed" intentionally hides the video grid on the Home page. Turn it off if you want to browse recommendations there.
- If you update the extension files, return to chrome://extensions and click Reload on the extension card.
